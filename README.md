# Memely.ia

Memely.ia es una startup de nutrición inteligente que utiliza
inteligencia artificial para generar dietas personalizadas.

## MVP

El usuario puede:

1. Registrarse
2. Ingresar datos físicos
3. Recibir dieta personalizada
4. Ver menú semanal

## Stack

Frontend

- HTML
- CSS
- JavaScript

Backend

- Python

Database

- SQLite
